# skill-unit-conversion

Local, offline unit converter. Length, mass, volume, time, and temperature.

## Examples

- `5km to miles`
- `convert 150 pounds to kilograms`
- `cups in a liter`
- `how many ml in a tablespoon?`
- `100 celsius to fahrenheit`

## Run tests

```powershell
cargo test -p skill-unit-conversion
```
